# PETAL BLADE — round 5

A samurai platformer for ARCADE-1: a Mario-like run-and-jump through a dusk
valley, drawn at the machine's native 480×270 and captured at 1080p with
`--scale 4`.

## What it is

You play a samurai crossing a tilemap world: run, jump the pits, slash oni and
kuwagata beetles with the katana, collect coins, and reach the vermilion torii
gate at the end. Three lives; touching an enemy or falling in a pit costs one.

* **Controls:** d-pad / arrows = move, **A** = jump, **B** = slash, **START** = retry.
* **Observable globals** (`--vars`): `state` (0 play / 1 win / 2 dead), `score`,
  `lives`, `px`, `py`, `cam_x`.

## How it is built

```
round5/
  gen_art.py      procedural art generator (stdlib-only, deterministic):
                  renders every sprite strip, writes assets.json, level1.txt
                  and level.h (the collision grid), plus a contact sheet.
  art/            the generated 4-bit sprite strips (PNG)
  assets.json     arc1-assetc manifest (palettes, sprites, animations, map)
  assets.h        generated by tools/arc1_assetc.py — the build truth
  level.h         generated collision grid (1 = solid)
  game.c          the guest (freestanding RV32IM C, no libc)
  petalblade.arc1 the built game image
  in_run.txt      a scripted play-through that reaches the torii (state = 1)
```

### Art direction

Dusk Japan. The palette is graded from deep indigo at the top of the sky through
violet and red to a warm gold at the horizon, with a pale moon and drifting
clouds. The samurai wears indigo armour with crimson lacing and a gold crescent
maedate; the oni are crimson with bone horns and tiger-skin trousers. The
background is three seamless parallax strips (far ridge → mid hills with pagoda
silhouettes → near treeline) drawn at 1/4, 1/2 and 3/4 camera speed.

The four round-5 reference sheets (the hand-drawn samurai walk cycle on 50×50
grids) are the style reference for the hero; the sprites are generated
procedurally so they fit the machine's 4-bit / 16-colour-per-bank format.

### Visual layers

1. sky gradient (12 interpolated bands) + stars
2. drifting clouds (screen-space)
3. moon (screen-fixed)
4. ridge / mid / near parallax strips
5. terrain tilemap (16 px tiles: grass, dirt, stone, brick, wood, bamboo, …)
6. goal torii, coins, enemies, player
7. dust particles (landing / kills)
8. HUD (score, lives, win/dead overlay)

## Build & run

```sh
python3 gen_art.py                                  # art + assets.json + level.h
python3 ../tools/arc1_assetc.py --assets assets.json --out-dir . --report
../build/arcade1 build game.c petalblade.arc1
../build/arcade1 run petalblade.arc1 --frames 120 --capture frame.png --scale 4
../build/arcade1 run petalblade.arc1 --input in_run.txt --vars state,score,lives
```

`--scale 4` upscales the 480×270 framebuffer to exactly 1920×1080.

## Notes

* Deterministic: particles are driven by the frame timer and a seeded LCG, so the
  same image + input script always replays bit-identically (verified).
* The guest is freestanding C for RV32IM — no libc, 32-bit types only.
